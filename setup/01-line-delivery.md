# LINEに配信する

**大原則：自動で送信しない。** 下書きを作るところまでを自動化して、
送信ボタンは必ず自分で押す。

```
一斉配信は取り消せない。
誤字も、誤ったリンクも、送った瞬間に全員に届く。
自動送信は、事故が起きたときに気づくのが遅れる。
```

## やり方は2つ

```
A. 管理画面で送る（推奨・設定ゼロ）
   AIが書いた下書きをコピーして、LINE公式の管理画面に貼る
   プレビューで確認してから送信

B. APIで下書きを作る（配信ツールを使っている場合）
   Lステップ等のAPIで下書きを登録し、管理画面で確認してから配信
   → お使いの配信ツールのAPIドキュメントに沿って下書きを登録する
```

## LINEで読まれる書き方

```
1行を短く
  スマホの画面幅で折り返さない長さ。20〜25字が目安

2〜3行ごとに空行
  詰まっていると開いた瞬間に閉じられる

装飾記号を使わない
  ** や ## は、そのまま文字として表示される
  強調したいなら【】か、行を分けて置く

区切りは記号で
  ━━━━━━━━━━ のような線で段落を分ける

1通が長くなるなら分割する
  3スクロール以上になったら、2通に分ける
```

## 送る前の確認

```
□ リンクは正しいか（実際にタップして確認する）
□ 誤字はないか（音読する）
□ 誰宛てか合っているか（セグメントを間違えていないか）
□ 送信時刻は適切か（深夜に送らない）
□ 前回の配信からの間隔は空いているか
```

**特にリンク。** 間違ったリンクを送ると、その配信は丸ごと無駄になる。

## 配信の記録を残す

送ったら `content/配信ログ.csv` に1行足す。

```
日付,種類,件名または冒頭,送信数,開封数,クリック数,メモ
2026-08-19,LINE一斉,新しい特典のお知らせ,1234,,,
```

**開封・クリックは翌日以降に埋める。**
数字が入ると、どの書き方が効いたかが見えるようになる。
