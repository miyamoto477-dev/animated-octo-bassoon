# Xに投稿する

## やり方は2つ

```
A. 手動で投稿する（推奨・設定ゼロ）
   AIが書いた下書きをコピーして貼る
   → 予約投稿もXの画面でできる

B. APIで投稿する
   X API v2 が必要。無料プランでも投稿はできるが、書き込み回数に上限がある
   設定はやや重い（OAuth の登録が要る）
```

**まずAで回す。** 投稿の型が固まってからBを検討すればいい。
自動投稿にしても、書く内容を考える時間は変わらない。

## APIを使う場合の準備

```
1. developer.x.com でアプリを作る
2. User authentication settings で読み書き権限を有効にする
3. Keys and tokens から
     API Key / API Secret
     Access Token / Access Token Secret
   を発行する
4. 保存する

   cat > ~/.x-credentials <<'END'
   API_KEY=...
   API_SECRET=...
   ACCESS_TOKEN=...
   ACCESS_TOKEN_SECRET=...
   END
   chmod 600 ~/.x-credentials
```

**無料プランの上限を先に確認する。** 月あたりの投稿数に制限があり、
超えると翌月まで投稿できなくなる。

## 投稿を管理する

`content/x投稿.csv` に貯めておく。

```
予定日,状態,型,1行目,投稿後URL,いいね,リポスト,保存
2026-08-19,下書き,やめたことリスト,◯◯で苦戦してたときにやめたこと3選,,,,
2026-08-20,投稿済,数字つきリスト,◯◯を3ヶ月やって分かったこと,https://x.com/...,12,3,8
```

**状態を「下書き / 予約済 / 投稿済」で管理する。**
下書きを溜めておくと、書く日と出す日を分けられる。

## 溜めてから出す

```
書く日   まとめて5〜10本の下書きを作る
出す日   1日1本ずつ出す

→ 毎日ゼロから考えると続かない
→ 調子のいい日にまとめて書いておく
```

## 反応を記録する

投稿したら、翌日にいいね・リポスト・**保存数**を記録する。

**保存数を最重視する。** いいねは反射で押せるが、
保存は「後で見返したい」という本気の反応。

```
3本たまったら、保存率（保存 ÷ 表示回数）の高い順に並べる
→ 上位の共通点が、あなたの勝ちパターン
→ その型を CLAUDE.md か memory/account-profile.md に足す
```
