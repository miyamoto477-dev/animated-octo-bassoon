# AI活用 × 記事制作以外の高単価案件リサーチ（2026-09-16 時点）

## 0. このメモの前提

- 目的：クラウドソーシングサイトで「AIを活用する／記事制作ではない」案件のうち、**単価の高いジャンル**を特定する
- **注意**：今回のセッションはネットワーク制限により `crowdworks.jp` / `lancers.jp` の案件一覧ページに直接アクセスできなかった。
  そのため下記は「**ジャンル別の単価相場と探し方**」であって、**今日時点の個別案件の生データではない**。
  実際の募集中案件は、後述の検索キーワードで各サイトを自分で叩いて確認すること。
- 数字は各出典の相場レンジをそのまま載せている（盛っていない）。案件によって上下する。

## 1. 前提となる市場の数字

- クラウドワークスの公式発表：**生成AI関連の契約案件数が前年比8.4倍**、単価は**生成AI関連以外の仕事の約2倍**。職種別ではITエンジニアが3.5倍。
- つまり「AIを使える」だけで単価レンジが変わるのは事実。ただし**記事制作は最も単価が崩れている領域**（文字単価0.1〜2.0円）なので、記事から外すのは方向として正しい。

## 2. 狙うべきジャンル（単価が高い順）

### ★★★ A. AIチャットボット／業務自動化の構築代行
- 相場：
  - シナリオ型（FAQ100問整備）：**20万円前後／件**
  - AI型（Dify・LINE Bot等）：**初期数十万円＋月額10〜30万円**
  - n8n等の業務自動化導入：**20万〜100万円**
- 使うツール：Dify / n8n / Make / GAS / Claude API / GPTs
- 強み：**保守運用の月額契約に繋がる**＝ストック収入になる。単発で終わらない。
- 参入難易度：ノーコードで組めるため非エンジニアでも入れる。実装者の供給がまだ薄い。
- 相性：LINE Bot構築は `employees/marketing`（インスタ→LINE導線設計）とほぼ同じ領域。**既存スキルの延長で売れる**。

### ★★★ B. 生成AI導入コンサル／社内活用レクチャー
- 相場：
  - 月次アドバイザリー：**月10〜50万円**
  - プロジェクト型：**20万〜200万円**
  - フリーランス向け専門エージェント（コンサルフリー等）：月額150万〜220万円がボリュームゾーン
- 中身：業務棚卸し → プロンプト設計 → 社内マニュアル化 → 研修
- 注意：クラウドソーシングの一般募集より、**エージェント経由の方が桁が違う**。クラウドソーシングは実績づくりの入口と割り切る。

### ★★ C. AI動画制作（ショート動画・AI広告動画）
- 相場：動画編集全般で**1本5,000円〜10万円超**。AI生成・キャラクター生成・口パク同期まで対応できると高単価帯に届く。
- AIで工数が落ちるので、**単価維持のまま実利益が伸びる**のがこのジャンルの本質的な旨味。
- 相性：SNS運用代行本体と直結。既存クライアントへのアップセルにしやすい。

### ★★ D. SNS運用代行そのもの（AI活用で内製効率化）
- 相場（代行会社の料金表ベース）：
  - 投稿代行のみ：**月5〜15万円**
  - 戦略・制作・分析込み：**月15〜30万円**
  - 広告・撮影込み：**月30万円〜**
  - 成果報酬型：投稿1件あたり8,000円〜のモデルも出てきている
- 重要：「AIに投げっぱなしのコンテンツはエンゲージメントが落ちる」という指摘が各社から出ている。
  **AIで効率化しつつ最終判断は人**、という体制を提案書に明記すると単価を守れる。→ `account-diagnosis-proposal` スキルで提案書化できる。

### ★ E. AI画像生成・プロンプト設計（ココナラ中心）
- 相場：プロンプト作成販売 1,000〜5,000円／画像生成系 5,000〜30,000円／使い方レッスン 3,000〜10,000円
- **単価は低い**。単体で追うより、A〜Dの案件を取るための実績・ポートフォリオ置き場として使うのが現実的。

## 3. サイトの使い分け（手数料）

| サイト | 手数料 | 向き |
| --- | --- | --- |
| クラウドワークス | 段階制（5〜20%） | **高単価案件ほど有利**。30万円の案件で手取り255,000円 |
| ココナラ | 一律22% | 低単価・出品型。30万円だと手取り234,000円（CWと約2.1万円差） |
| ランサーズ | 段階制 | 「生成AI活用・業務効率化」カテゴリが独立して存在する |

→ **20万円を超える案件はココナラで受けない**。クラウドワークス／ランサーズ、または直契約に寄せる。

## 4. 実際に叩く検索キーワード

各サイトの仕事検索に、そのまま入れる。

**A（自動化・チャットボット）**
`Dify` / `n8n` / `LINE Bot 構築` / `チャットボット 構築` / `GAS 業務効率化` / `Claude API` / `AIエージェント 開発`

**B（コンサル・研修）**
`生成AI 導入支援` / `AI 社内研修` / `プロンプト設計` / `AI活用 コンサル` / `業務棚卸し AI`

**C（動画）**
`AI 動画生成` / `ショート動画 AI` / `Sora` / `AI広告 クリエイティブ` / `VSEO`

**D（SNS）**
`SNS運用代行 ディレクター` / `Instagram 運用 戦略` / `SNS 分析 レポート`

**絞り込みのコツ**
- 予算で降順ソート → 「固定報酬 10万円以上」or「月額」でフィルタ
- 「継続」「長期」「月額」が入っている募集を優先（単発の値切り案件を避けられる）
- 逆に「記事」「ライティング」「文字単価」はNGワードとして目視で弾く

## 5. 直近の動き方（おすすめ順）

1. **A（自動化・チャットボット）を主軸に据える**。単価・ストック性・供給の薄さの3つが揃っている唯一のジャンル。
2. Difyで**LINE Bot のデモを1つ自作**して、ポートフォリオにする（`employees/marketing` のLINE導線設計と中身が同じなので流用できる）。
3. 既存／見込みのSNSクライアントに、C（AI動画）とA（LINE自動化）を**アップセル**として出す。新規開拓より確実に単価が上がる。
4. ココナラは低単価出品で実績数を稼ぐ場所として限定利用。本命の受注はクラウドワークス／ランサーズ／直契約。
