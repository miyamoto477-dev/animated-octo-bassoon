# 特典①｜AI社員「SNS運用代行」スターターOS

3daysブートキャンプDay3にご参加いただき、ありがとうございます。
この特典は、SNS運用の企画・台本・サムネ・分析・提案を担当する「AI社員」の土台一式です。

## このフォルダに入っているもの

| ファイル | 何か |
| --- | --- |
| `特典①_AI社員スターターOS.zip` | **これをダウンロードしてください。** AI社員の本体（フォルダ一式） |
| `CLAUDE.md（AI社員の役割定義）.md` | zipの中に入っているファイルの中身確認用 |
| `README（セットアップ手順）.md` | zipの中に入っているセットアップ手順の中身確認用 |
| `memory_account-profile（記入シート）.md` | zipの中に入っているアカウント情報の記入シート |
| `エヌイチ式 SNS運用管理シート` | AI社員が読み書きする管理シート（Googleスプレッドシート） |

zipの中身が気になる方のために、主要ファイルをそのまま置いています。
**使うだけならzipだけダウンロードすればOKです。**

## 使い方（5分）

### STEP1｜Claude Codeを入れる（まだの方）

登録特典「Claude Code セットアップガイド」の手順で導入してください。

### STEP2｜zipを解凍して好きな場所に置く

デスクトップなどに置いてください。

### STEP3｜Claude Codeでそのフォルダを開く

ターミナルで次を実行します。

```
cd （解凍したai-shain-osフォルダのパス）
claude
```

※パス入力が面倒なら、`cd ` と打ってからフォルダをターミナルにドラッグ＆ドロップすると自動で入ります。

### STEP4｜動作確認

`あなたの役割を教えて` と話しかけてください。
SNS運用代行のAI社員として役割を説明すれば成功です。

### STEP5｜管理シートを連携する

このフォルダにある「エヌイチ式 SNS運用管理シート」を自分のドライブにコピー（ファイル → コピーを作成）し、そのURLをClaude Codeに伝えてください。

```
このSNS運用管理シートを使います：（コピーしたシートのURL）
```

## ⚠️ 解凍したのに中身が少なく見える方へ

skillは `.claude/skills/` という**ドットから始まる隠しフォルダ**に入っています。
Macのfinderは標準でこれを非表示にするため「中身が空」に見えますが、**正常です**。

見たい場合はfinderで `command + shift + .`（コマンド＋シフト＋ピリオド）を押してください。もう一度押すと元に戻ります。

## 特典②③④との関係

**この特典①のzipには、特典②③④のskillもすべて含まれています。**
特典①だけ入れれば、5つのskillが全部使える状態になります。

特典②③④は「すでに自分のClaude Code環境があるので、skillだけ単体で足したい」という方向けに、個別で切り出したものです。
特典①を入れた方は、特典②③④のダウンロードは必須ではありません。
