# Claude × A8.net アフィリエイトの始め方

AI社員スターターOSに追加した「アフィリエイト部」の使い方ガイドです。
運用しているSNSアカウントを、A8.netのアフィリエイトでも収益化するための流れをまとめています。

## 全体像

```text
① A8.netに登録・メディア登録（ユーザー）
② 案件を選ぶ           → a8-program-select
③ 提携申請（ユーザー）   ※申請文はClaudeが下書き
④ 紹介投稿を作る        → affiliate-post-gen
⑤ 公開前チェック        → affiliate-compliance-check ★必須
⑥ リンクを貼って投稿（ユーザー）
⑦ 月末に成果を分析      → a8-report-analyze
⑧ 案件の継続／差し替えを判断 → ②へ戻る
```

Claudeは②④⑤⑦を担当します。①③⑥のA8.net管理画面の操作はユーザー本人が行います（A8.netに一般アフィリエイター向けの公開APIがないため、自動連携はしない設計です）。

## STEP1｜A8.netの準備（ユーザー）

1. [A8.net](https://www.a8.net/) に登録する
2. 紹介に使うメディア（Instagramアカウント／ブログなど）を登録する
3. 管理画面の「プログラム検索」を開けるようにしておく

## STEP2｜案件を選ぶ

Claude Codeでこのフォルダを開き、こう話しかけます。

```text
A8の案件選んで
```

Claudeが `memory/account-profile.md` のジャンル・ターゲットを読み、**A8.netでの検索条件**を出します。その条件で検索した結果を、コピペかスクリーンショットで渡してください。

```text
（検索結果を貼り付け）この中から選んで
```

候補5件が比較表（報酬・成果条件・承認率・EPC・クッキー期間・SNS掲載可否）になり、1〜2件に絞られます。選定メモは `employees/affiliate/programs/` に残ります。

> Claudeは案件データベースを持っていません。実データを渡さないと案件名や単価は出しません（推測で書かないためです）。

## STEP3｜提携申請（ユーザー）

審査ありの案件では、申請文の下書きをClaudeが作ります。内容を自分の事実に合わせて直してから、管理画面のフォームに貼ってください。フォロワー数・実績は盛らないこと。

提携が通ったら、こう伝えると台帳（`memory/affiliate-programs.md`）に記録されます。

```text
〇〇と提携できた。台帳に入れといて
```

## STEP4｜紹介投稿を作る

```text
この案件の投稿作って 案件:〇〇（使用歴3ヶ月）
```

**「実際に使っているか」を必ず聞かれます。** 使っていない案件では体験談型の構成は作らず、「公式情報をまとめたもの」と明記する形になります。ここを曖昧にするとアカウントの信頼が壊れるため、正直に答えてください。

出てくるもの：リール台本／フィード構成／キャプション（PR表記入り）／ストーリーズ／導線の指示。

## STEP5｜公開前チェック（必須）

```text
この投稿チェックして
```

- **ステマ規制**：PR表記が冒頭にあるか（2023年10月1日施行。広告と分からない表示は景品表示法違反）
- **薬機法**：「治る」「痩せる」など効果の断定がないか
- **景表法**：根拠のない「No.1」「今だけ」がないか

「修正必須／要確認／公開OK」の判定と、原文→修正案が出ます。
※これは法的助言ではありません。最終判断はご自身と広告主の確認で行ってください。

## STEP6｜リンクを貼って投稿（ユーザー）

A8.netの素材リンクをコピーし、導線の指示どおりに貼ります。

```text
投稿のCTA → プロフィールリンク → まとめページ（lit.link等）→ A8素材リンク
```

Instagramは投稿本文からリンクを飛ばせないため、この多段導線が前提です。

## STEP7｜月末に成果を分析

A8.net管理画面の「レポート」からCSVをダウンロードして、

```text
A8のレポート分析して ~/Downloads/report_202609.csv
```

クリック・発生・確定・承認率・EPCが集計され、ボトルネック（導線／案件ミスマッチ／承認率／露出不足）が1箇所に特定されます。レポートは `employees/affiliate/reports/YYYY-MM.md` に残ります。

## 最初にやるべきこと

`memory/account-profile.md` のジャンル・ターゲットを埋めてください。ここが空だと、案件選定が毎回ヒアリングから始まります。

## 大事な原則（アフィリエイト部の方針）

1. 使っていない商品を、使ったように紹介しない
2. PR表記を必ず冒頭に入れる
3. 報酬単価ではなく、読者の悩みに合うかで選ぶ
4. 数字（成果・承認率）を誇張しない
5. **A8.netと広告主の規約がこのOSの記述より優先**。判断がつかないときは掲載を止めて確認する
