# サムネ・表紙ワード生成スキル

## 概要

リールの表紙やYouTubeサムネイルに乗せる短いテキスト案を、複数パターン生成する。
`sns-script-gen` で作った台本のテーマをそのまま渡すと相性がよい。

## 実行手順

### STEP1｜テーマと訴求ポイントを確認

1. 投稿テーマ（何についての投稿か）
2. 一番伝えたい一点（数字・変化・警告・お得さのどれが核か）
3. ターゲット（誰が見て「自分ごと」と思うか）

### STEP2｜6つのパターンで案を出す

以下のパターンごとに2〜3案ずつ、合計12〜18案を出す。

| パターン | 特徴 | 例の型 |
| --- | --- | --- |
| 数字訴求型 | 具体的な数字を主役にする | 「〇〇円→〇〇円」「たった〇日で」「〇人が変わった」 |
| 感情トリガー型 | 驚き・悔しさ・焦りを煽る短い言葉 | 「知らないと損」「ズルい」「まさかの結果」 |
| 疑問・呼びかけ型 | ターゲットに直接問いかける | 「〇〇で悩んでませんか？」「これやってる？」 |
| Before/After型 | 変化を一言で見せる | 「同じ人物です」「たった1回でこの差」 |
| 断定・言い切り型 | 権威性のある言い切り | 「〇〇はこれが正解」「プロが教えます」 |
| ターゲット限定型 | 見てほしい人を明示する | 「初心者向け」「〇〇な人だけ見て」 |

### STEP3｜文字数と可読性のチェック

- 表紙のメインテキストは全角10〜16文字程度に収める（スマホで一瞬で読める長さ）
- 数字・キーワードは強調（別行・別サイズ想定）で目立たせる位置を提案する
- 同じ言い回しの案を連続させない（パターンを必ず散らす）

### STEP4｜出力形式

```text
【サムネワード案】投稿テーマ：〇〇

数字訴求型：
・（案1）
・（案2）

感情トリガー型：
・（案1）
・（案2）

疑問・呼びかけ型：
・（案1）
・（案2）

Before/After型：
・（案1）
・（案2）

断定・言い切り型：
・（案1）
・（案2）

ターゲット限定型：
・（案1）
・（案2）

おすすめ1案：（一番クリック率が見込める案とその理由）
```

## 注意点

- 誇大・虚偽になる数字や効果表現は使わない
- 過度に不安を煽る表現（恐怖訴求のしすぎ）は避け、事実ベースの範囲に収める
- 同じアカウントで表紙のトンマナ（フォント・色）を統一したい場合は、案のテイストもそれに合わせて絞り込む
