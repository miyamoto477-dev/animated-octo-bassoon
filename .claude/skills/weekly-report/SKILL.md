# 週次レポートスキル

## 概要

毎週月曜の朝、先週1週間の運用結果を振り返るスキル。`client-report-gen` はクライアント向けの月次報告書だが、このスキルは社内向け・週次の振り返りに使う。

## 実行手順

### STEP1｜各部署ログの集計

先週1週間分の `employees/research/` `employees/creative/` `employees/community/` `employees/marketing/` のログを集計する。SNS運用管理シートと連携していれば、そちらの数値も読み込む。

### STEP2｜数字のまとめ

以下の数字をまとめる。数字が無ければユーザーに確認する。

- フォロワー増減
- 投稿数（フィード投稿・リール・ストーリーズ別）
- 保存数・コメント数の合計
- LINE新規登録数
- DM対応件数

### STEP3｜良かった点・悪かった点

先週の良かった点・悪かった点を各3つ挙げる。

### STEP4｜来週の改善案

来週の改善案を3つ提示する。

### STEP5｜保存

`reviews/YYYY-Www.md` に保存する。

## 注意点

- 数字は誇張しない。悪い数字も隠さずそのまま報告する
