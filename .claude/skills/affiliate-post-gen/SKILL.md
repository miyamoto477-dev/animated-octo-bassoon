# アフィリエイト紹介投稿生成スキル

## 概要

提携した案件を、押し売りにならない形でSNS投稿に落とすスキル。方針は `employees/affiliate/CLAUDE.md` に準拠する。

Instagramは投稿本文からリンクを飛ばせないため、**投稿単体で売るのではなく「プロフィールへ送る」設計**にする。

## 引数

- 案件名：ユーザーから受け取る（`employees/affiliate/programs/{案件名}.md` があれば読む）
- 使用実績：**必ず確認する**。「使っている／使っていない」で構成が変わる
- 媒体：Instagram／Threads（未指定なら**両方**作るか確認する。同じ文章を使い回さない）
- フォーマット：Instagramはリール／フィード／ストーリーズ、Threadsは単発／ツリー（未指定ならInstagramはリール、Threadsは単発を既定とする）

## 実行手順

### STEP1｜前提情報を揃える

1. `memory/account-profile.md` でジャンル・ターゲット・トンマナを読む
2. `employees/affiliate/programs/{案件名}.md` で成果条件・報酬・掲載条件を読む（無ければヒアリング）
3. 案件の掲載条件（SNS掲載可否・使用可能な文言）に反する構成を作らない

### STEP2｜切り口を決める

**商品紹介から入らない。読者の悩みから入る。** 次のどれかを選び、理由を1行添える。

| 切り口 | 向いているケース |
| --- | --- |
| 悩み解決型 | 「〇〇で困っていた私が変えたこと」 |
| 比較検討型 | 「A・B・Cを試して残ったのはこれ」 |
| Before/After型 | 実際に使っていて変化を語れる場合のみ |
| 失敗談型 | 「これを選ぶ前にやらかした3つ」 |
| 知識提供型 | 未使用案件でも成立する（商品は最後に選択肢の1つとして置く） |

**未使用の案件では Before/After型・体験談型を使わない。** 知識提供型か比較検討型にし、「実際には使っておらず、公式情報と口コミを整理したもの」と本文に明記する。

### STEP3-A｜Instagram用の構成を作る

台本の生成そのものは `sns-script-gen`、フィード10枚構成は `feed-post-gen`、サムネ文言は `sns-thumbword-gen` に渡す。このスキルはアフィリエイト固有の要素を足す。

- 冒頭：PR表記（1行目）
- 本編8割：悩み・原因・解決の考え方（商品名を出さない）
- 商品の登場は終盤2割：「私はこれを使った」または「選択肢のひとつ」
- デメリット・向かない人を必ず1つ入れる（メリットだけの投稿は信頼を落とす）
- CTA：`プロフィールのリンクから見れます` の1つに絞る

キャプションの型：

```text
PR

〇〇（フック1行）

（本文：悩み→原因→解決）

▼向いている人
・〇〇
▼向いていない人
・〇〇

詳細はプロフィールのリンクから💐
（@アカウント名）

#タグ #タグ #タグ
```

- 1行目のPR表記は削らない。ハッシュタグの中に紛れ込ませない
- 投稿本文にURLを書かない（Instagramではクリックできず、離脱の原因になる）
- 価格・キャンペーン期間を書く場合は、公式の現在の表記と一致しているかユーザーに確認する

### STEP3-B｜Threads用の構成を作る

Threadsは**本文にクリックできるリンクを置ける**。Instagramのキャプションを流用せず、テキスト前提で書き直す。

- 1投稿500文字以内。1投稿1テーマ
- 1行目：PR表記 → 2行目：フック（体言止め・言い切り・問いのどれか）
- ビジュアル前提の表現（「スワイプして」「保存してね」）を使わない
- 語りかけ・問いかけで終えて返信を誘う（返信とリポストが伸びの起点）
- リンクは1投稿1つまで

**単発型**

```text
PR

〇〇（フックの1行）

（本文：悩みの言語化 → 原因 → こう考えると解決する）

私は〇〇を使ってこうなった（未使用なら「調べた範囲では」と書く）
合わない人：〇〇

詳しくはこちら
（ここにA8の素材リンクを貼る）
```

**ツリー型**（本編で価値を出し、最後の返信でリンクを出す）

```text
1投稿目：PR＋フック＋結論（リンクなし）
2投稿目：理由・具体
3投稿目：失敗例／向かない人
4投稿目：まとめ＋（ここにA8の素材リンクを貼る）
```

ツリーは1投稿目だけが単独で拡散されるため、**PR表記は必ず1投稿目に置く**。

### STEP4｜Threads → Instagram の順で回す

両媒体を作る場合、運用順をセットで伝える。

```text
1. Threadsで先にテーマを出す（制作コストが低い）
2. 反応（返信・リポスト）が良かったテーマだけを
3. Instagramのリール／フィードとして作り込む
```

反応が取れなかったテーマをInstagramで作り込まない。

### STEP5｜導線を明記する

投稿とセットで、リンクの置き場所を媒体別に指定して渡す。

```text
【導線】
Instagram：投稿CTA → プロフィールリンク → まとめページ（lit.link等）→ A8素材リンク
　　　　　　ストーリーズはリンクスタンプで直接（投稿翌日・夜に1回）
Threads　：投稿本文またはツリー最終返信から直接 → A8素材リンク
LINE　　 ：登録者向けは別途 line-sequence-gen の文脈に合わせる
```

**Threadsに直リンクを貼る前に、その案件がThreads掲載可か、A8.netのメディア登録にThreadsアカウントが入っているかをユーザーに確認する。** 未確認のままリンク前提の構成を渡さない（プロフィール導線版を代替として添える）。

A8.netの素材リンクの発行・貼り付けはユーザーが行う。Claudeはリンクを捏造しない（`（ここにA8の素材リンクを貼る）` と書く）。

### STEP6｜法令チェックへ渡す

生成後、必ず `affiliate-compliance-check` を続けて実行するか、ユーザーに実行を促す。チェック前の投稿を「完成」と呼ばない。

### STEP7｜保存

- フィード投稿 → `employees/creative/feed/YYYY-MM-DD_{案件名}.md`
- リール台本 → `sns-script-gen` の保存先に従う
- Threads投稿 → `employees/creative/threads/YYYY-MM-DD_{案件名}.md`
- どこに保存したかを最後に伝える

## 注意点

- 使っていない商品を、使ったかのように書かない（最優先）
- 効果を断定しない。体感は「個人の感想」として書く
- 1投稿1案件。複数案件を同時に入れない
- InstagramとThreadsで同じ文章をそのまま使い回さない（媒体の性質が違う）
- 成果報酬の金額や「稼げます」系の訴求を投稿内で語らない

## 呼び出し例

```
この案件の投稿作って 案件:〇〇（使用歴3ヶ月）媒体:Threads
この案件の投稿作って 案件:〇〇 媒体:両方
```
