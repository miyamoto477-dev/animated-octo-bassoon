# A8.net 成果レポート分析スキル

## 概要

A8.netの成果データを月次で読み、「案件を続けるか・差し替えるか・導線を直すか」を判断するスキル。方針は `employees/affiliate/CLAUDE.md` に準拠する。

## 入力の受け取り方

A8.netに一般アフィリエイター向けの公開APIがない前提のため、データは次のどちらかで受け取る。

1. **CSV**：管理画面 →「レポート」からダウンロードしたCSVファイルのパスを教えてもらう
2. **手入力**：管理画面の数字を貼り付けてもらう（インプレッション／クリック／発生件数／発生報酬／確定件数／確定報酬）

## 実行手順

### STEP1｜CSVを読む

A8.netのCSVは **Shift_JIS（cp932）** で出力されることが多い。UTF-8で文字化けする場合は cp932 で読み直す。ヘッダー行の前に説明行が入っている場合はスキップする。

```python
import pandas as pd
for enc in ("cp932", "utf-8-sig", "utf-8"):
    try:
        df = pd.read_csv(path, encoding=enc)
        break
    except UnicodeDecodeError:
        continue
print(df.columns.tolist())
print(df.head())
```

列名はレポート種別で変わるため、**必ず実際の列名を確認してから集計する**。列の意味が推測できない場合はユーザーに聞く。

### STEP2｜指標を計算する

| 指標 | 計算式 | 見方 |
| --- | --- | --- |
| CTR | クリック÷インプレッション | 素材・導線の入口が機能しているか |
| CVR | 発生件数÷クリック | 案件と読者のズレ、LPとの相性 |
| 承認率 | 確定件数÷発生件数 | 低いと発生しても報酬にならない |
| EPC | 確定報酬÷クリック | **案件比較の主指標**。単価より実態に近い |
| 案件別構成比 | 案件ごとの確定報酬÷合計 | 1案件依存になっていないか |

数値は小数第1位まで。分母が0の場合は `算出不可` と書き、0や推測値で埋めない。

### STEP3｜ボトルネックを特定する

数字の並びから、詰まっている場所を1箇所に絞る。

```text
クリックが少ない      → 導線の問題（プロフィール・ストーリーズ・CTAの頻度）
クリックはあるがCVRが低い → 案件と読者のミスマッチ、または期待値のズレた紹介文
発生はあるが承認率が低い  → 成果条件の見直し、キャンセルされやすい案件
全体が少ない         → 露出（投稿本数）そのものが不足
```

### STEP4｜レポートを書く

```text
【A8.net 成果レポート 〇年〇月】

■ サマリー
・クリック：〇〇（前月比 〇%）
・発生：〇件／〇〇円
・確定：〇件／〇〇円
・承認率：〇.〇%
・EPC：〇.〇円

■ 案件別
| 案件 | クリック | 発生 | 確定 | 承認率 | EPC |

■ ボトルネック
〇〇（根拠：〇〇）

■ 来月の打ち手（2つまで）
1. 〇〇
2. 〇〇
```

### STEP5｜案件の継続判断

各案件に「継続／様子見／差し替え」を付け、理由を1行。差し替え判断になった案件は `a8-program-select` での再選定を提案する。

### STEP6｜保存

`employees/affiliate/reports/YYYY-MM.md` に保存し、`memory/affiliate-programs.md` の台帳のEPC・承認率を更新する。

## 注意点

- 数字は改ざん・誇張しない。成果0の月も「0件」とそのまま書く
- 発生report と確定report を混同しない（発生＝まだ報酬ではない）
- 承認率は母数が小さいと意味を持たない。発生10件未満の場合は「母数が少なく判断保留」と明記する
- 前月データが無い月は比較セクションを省略し、理由を書く
- CSVに含まれる広告主名・成果の個別データは外部に流用しない

```
A8のレポート分析して ~/Downloads/report_202609.csv
```
