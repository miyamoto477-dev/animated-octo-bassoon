# A8.net 案件選定スキル

## 概要

A8.netで提携する案件を、報酬単価ではなく「読者の悩みに合うか」で選ぶスキル。方針は `employees/affiliate/CLAUDE.md` に準拠する。

## 前提：Claudeは案件データベースを持たない

Claudeは A8.net の管理画面にアクセスできず、案件名・報酬単価・承認率を自前で知ることもできない。**実在しない案件名や単価を推測で書かない。** 必ず次のどちらかで実データを受け取る。

- ユーザーがA8.net管理画面の「プログラム検索」結果をコピペ／スクリーンショットで渡す
- ユーザーが案件名と条件を口頭で伝える

データが無い状態で依頼された場合は、STEP1の検索軸だけを出して、検索結果を持ってきてもらう。

## 実行手順

### STEP1｜検索軸を組み立てる

`memory/account-profile.md` のジャンル・ターゲット・商品を読み、A8.net管理画面での検索条件を提示する。

```text
【A8.netプログラム検索の条件】
・カテゴリ：〇〇
・キーワード：〇〇／〇〇／〇〇
・絞り込み：SNS掲載可（Instagram・Threadsで使えるか）／ 成果条件が「無料登録」or「購入」
・並び替え：EPC（1クリックあたりの平均報酬）の高い順で一度見る
```

あわせて、この条件で見るべき理由を1〜2行添える。

### STEP2｜候補を比較表にする

受け取った検索結果から候補5件を、次の7項目で比較表にする。分からない項目は憶測で埋めず `不明（要確認）` と書く。

| 項目 | 見るポイント |
| --- | --- |
| 案件名・広告主 | — |
| 成果報酬 | 単価と報酬形態（定額／料率） |
| 成果条件 | 何が起きたら報酬発生か（無料登録・申込・購入・初回課金） |
| 承認率 | 低い案件は発生しても確定しない。表示があれば必ず記録する |
| EPC | 1クリックあたりの平均報酬。単価より実態に近い |
| クッキー（再訪）期間 | 短い案件はSNS経由だと不利になりやすい |
| SNS掲載可否・掲載条件 | **Instagram・Threadsで使えるか**、素材の改変可否、リンクの直貼り可否 |

### STEP3｜ターゲット適合度を採点する

5件それぞれを3軸で ○△× 評価し、理由を1行ずつ書く。

- **悩み適合**：`memory/account-profile.md` のターゲットの悩みを直接解決するか
- **導線適合**：媒体ごとに見る。Threadsは本文から直リンクできるので申込ハードルが高い案件も戦えるが、Instagramはプロフ→まとめページ→申込の多段になるため、**申込に時間のかかる案件ほど不利**。両媒体で使える案件を優先する
- **信頼リスク**：自分が使っていない／怪しい訴求の商材でないか

### STEP4｜1〜2件に絞る

採点をもとに1〜2件に絞り、「なぜこれを選び、他を落としたか」を明記する。報酬単価だけを根拠にした選定はしない。

### STEP5｜提携申請文の下書き

審査ありの案件向けに、申請フォームに貼れる文面を作る（150〜300字）。次を含める。

- 運用しているメディア（アカウント名・ジャンル・フォロワー規模）
- 想定読者と、なぜこの商材が合うか
- どんな形で紹介するか（リール／フィード／ストーリーズ／LINE）

誇張した実績を書かない。フォロワー数・実績は事実のみ。

### STEP6｜保存

- 選定メモ → `employees/affiliate/programs/{案件名}.md`
- 提携が通ったら `memory/affiliate-programs.md` の台帳に1行追記する（提携日・成果条件・承認率・掲載場所）

## 注意点

- 案件名・単価・承認率を推測で書かない。未取得のデータは `不明（要確認）` と書く
- 各広告主の提携条件（SNS掲載可否、商標キーワード出稿の禁止、クリエイティブ改変の可否）はユーザー本人に管理画面で確認してもらう
- Threadsは投稿本文に直リンクを貼れるが、広告主が媒体を限定している場合がある。Threads掲載の可否が読み取れない案件は `要確認` として扱い、確認が取れるまでリンク直貼り前提の設計をしない
- A8.netのメディア登録にInstagramとThreadsの**両方**が登録されているか確認する。媒体を分けて登録しておくと、後で `a8-report-analyze` で媒体別の成果を比較できる
- セルフバック（自己アフィリエイト）は案件ごとに可否・条件が異なる。使う場合は必ず管理画面の記載を確認する
- 選定後は `affiliate-post-gen` へ、公開前には `affiliate-compliance-check` へ繋ぐことを提案する
