# コメント文一括生成スキル

## 概要

毎朝のコメント周り用の文案を一括生成するスキル。ルールは `employees/community/CLAUDE.md` のNGルールに準拠する。

## 引数

- 件数：デフォルト20件

## 実行手順

### STEP1｜対象投稿の収集

リサーチ部の最新ログ、またはユーザーから、ターゲットアカウントの今日の投稿を受け取る。

### STEP2｜コメント文を作成

各投稿についてコメント文を作成する。

### STEP3｜ルール適用

- 60〜100文字
- 投稿内容に具体的に言及する
- 自分の経験を1〜2文添える
- 質問で終わる
- 「素敵ですね」だけの定型文はNG
- 宣伝・URL付きコメントは禁止、絵文字は1個まで

### STEP4｜保存

`employees/community/comments/YYYY-MM-DD.md` に保存する。

### STEP5｜送信先リスト

送信先アカウントのリストも添える。

## 呼び出し例

```
コメント文作って 件数:20
```
