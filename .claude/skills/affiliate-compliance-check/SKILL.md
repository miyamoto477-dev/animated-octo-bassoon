# アフィリエイト表現チェックスキル

## 概要

アフィリエイト投稿を公開する前に、法令・規約上リスクのある表現を洗い出して言い換えるスキル。方針は `employees/affiliate/CLAUDE.md` に準拠する。

**このスキルは法的助言ではない。** 最終判断はユーザー本人と広告主（および必要なら専門家）が行う。グレーな表現は「黒」寄りに倒して指摘する。

## 実行手順

### STEP1｜PR表記のチェック（ステマ規制）

景品表示法の指定告示（2023年10月1日施行）により、広告なのに広告と分からない表示は違反になる。次を確認する。

- [ ] 「PR」「広告」「プロモーションを含みます」等の表記があるか
- [ ] 位置が**冒頭**か（キャプション末尾・「もっと見る」以降に隠れていないか）
- [ ] 動画の場合、テロップ／音声／概要欄のいずれかで明示されているか
- [ ] ハッシュタグの羅列に埋もれていないか（`#PR` を大量タグの末尾に置くのはNG寄り）
- [ ] 小さすぎる・薄い文字色で視認しづらくなっていないか
- [ ] **Threadsのツリー投稿の場合**、PR表記が**1投稿目**にあるか（1投稿目だけが単独で拡散されるため、2投稿目以降に置くのはNG）
- [ ] Instagramの投稿本文にクリックできないURLを書いていないか（違反ではないが離脱要因）

NGなら、修正後の1行目を具体的に書いて示す。

### STEP2｜薬機法のチェック（化粧品・健康食品・サプリ・医療系）

医薬品でないものに医薬品的な効能を語らせない。次の型を検出する。

| NGの型 | 例 | 言い換えの方向 |
| --- | --- | --- |
| 治療・治癒 | 「ニキビが治る」「アトピーが改善」 | 化粧品の効能効果の範囲内の表現に留める |
| 身体変化の断定 | 「飲むだけで痩せる」「バストアップ」 | 体感の個人的感想＋個人差の明記 |
| 即効性 | 「3日で〇〇」「すぐ効く」 | 使用期間の事実のみ記載 |
| 予防・防止 | 「風邪を予防する」 | 削除 |
| 医薬品的な部位・症状 | 「花粉症に」「関節痛に」 | 削除 |
| 最大級表現 | 「最強」「No.1」「絶対」 | 客観的根拠（出典・調査名）が無ければ削除 |

検出した箇所は「原文 → 修正案」の形で並べる。

### STEP3｜景表法のチェック（優良誤認・有利誤認）

- [ ] 効果・性能を実際より良く見せていないか（**優良誤認**）
- [ ] 価格・特典・期間を実際より有利に見せていないか（**有利誤認**）
- [ ] 「今だけ」「残りわずか」が事実か（常時やっているなら書かない）
- [ ] 「No.1」「満足度〇%」に出典（調査機関・期間・対象）が付いているか
- [ ] 体験談が実体験か。未使用なら「実際には使っておらず、公式情報をまとめたもの」と明記しているか
- [ ] 二重価格表示（「通常〇円→〇円」）の通常価格が実在するか

### STEP4｜規約面のチェック

- [ ] 広告主が禁止している訴求・キーワードを使っていないか
- [ ] クリエイティブ（画像・文言）を無断改変していないか
- [ ] 公式サイトの文章・画像をそのまま転載していないか（著作権）
- [ ] 他社商品の比較で、根拠のない断定的な優劣を書いていないか

### STEP5｜判定を出す

```text
【チェック結果】
判定：公開OK ／ 修正必須 ／ 要確認（広告主に問い合わせ）

■ 修正必須（〇件）
1. 原文：「〇〇」
   理由：薬機法／効能の断定にあたる
   修正案：「〇〇」

■ 要確認（〇件）
1. 〇〇 → 広告主の提携条件で可否を確認

■ 問題なし
・PR表記：冒頭1行目に「PR」あり
```

修正必須が0件でも、そう書く。問題を作り出さない。

## 注意点

- このスキルの出力は法的助言ではない旨を、判定の末尾に必ず1行添える
- 判断がグレーな表現は「要確認」に入れ、勝手にOKにしない
- 表現を弱めた結果、事実と違う記述になっていないか最後に読み返す
