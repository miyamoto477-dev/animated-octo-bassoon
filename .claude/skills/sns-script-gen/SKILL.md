# SNS台本自動生成スキル

## 概要

投稿テーマを渡すだけで、フック（冒頭1〜3秒）・構成（本編の流れ）・CTA（締めの一言）が揃った台本を生成する。
`sns-kikaku-30` スキルで出した企画をそのまま渡すと相性がよい。

## 実行手順

### STEP1｜テーマとアカウント情報を確認

以下が不明な場合は先に確認する。

1. 投稿テーマ（何についての投稿か）
2. ターゲット（誰に向けた投稿か）
3. ゴール（保存を狙うのか、プロフ誘導したいのか、問い合わせに繋げたいのか）
4. フォーマット（リール30秒／リール60秒／フィード投稿／ストーリーズ）

### STEP2｜テーマに最も合う「型」を1つ選ぶ

以下10の型から、テーマの性質に最も合うものを選ぶ（迷ったら悩み共感型かハウツー型が汎用性が高い）。

| 型 | 向いているテーマ |
| --- | --- |
| ① Before/After系 | 施術・制作物・数字の変化を見せられるテーマ |
| ② 悩み共感→解決系 | ターゲットの「あるある」がはっきりしているテーマ |
| ③ ランキング/比較系 | 複数の選択肢・商品・方法を比べられるテーマ |
| ④ 実演・ハウツー系 | 手順化できる作業・やり方の紹介 |
| ⑤ 意外性・逆説系 | 常識と違う事実・データがあるテーマ |
| ⑥ 実績・数字訴求系 | 実績数値・アンケート結果があるテーマ |
| ⑦ Q&A・疑問解消系 | よく聞かれる質問がすでにあるテーマ |
| ⑧ ストーリー・体験談系 | 運用者自身や顧客のエピソードがあるテーマ |
| ⑨ リスト・まとめ系 | 情報を並べるだけで価値になるテーマ |
| ⑩ 警告・注意喚起系 | 失敗例・リスクを扱うテーマ |

### STEP3｜台本を組み立てる

選んだ型に沿って、以下3パートを具体的に書く。

**フック（冒頭1〜3秒）**
テーマの内容を当てはめた、断定的で短い一言にする。疑問形・数字・意外性のいずれかを必ず含める。

**構成（本編）**
型ごとの流れ（下記参照）に沿って、テーマの具体的な内容を3〜5ステップで展開する。1ステップ＝1カット・5〜8秒を目安にする。

- Before/After系: Before映像→工程/施策の要点→After映像→差の理由
- 悩み共感→解決系: 悩みの列挙→共感の一言→原因→解決策
- ランキング/比較系: 前置き→ワースト/選択肢を順に→理由→結論
- 実演・ハウツー系: 準備物→手順1→手順2→手順3→完成
- 意外性・逆説系: 常識の提示→検証/根拠→意外な結論
- 実績・数字訴求系: 実績数字→内訳・理由→再現性の一言
- Q&A・疑問解消系: 質問提示→回答→補足・注意点
- ストーリー・体験談系: 過去の状態→転機・気づき→今の状態
- リスト・まとめ系: タイトル→項目を淡々と→締めの一言
- 警告・注意喚起系: 警告→理由・事例→正しい対処法

**CTA（締め）**
ゴールに応じて選ぶ。

- 保存を狙う: 「保存して後で見返して」「保存版なのであとで試してみて」
- プロフ誘導: 「詳しいやり方はプロフのリンクから」「続きはハイライトに保存してます」
- 問い合わせ誘導: 「気になる人はコメント／DMで聞いてください」
- 継続フォロー: 「同じシリーズ続けるのでフォローして待っててください」

### STEP4｜出力形式

```text
【台本】投稿テーマ：〇〇（型：②悩み共感→解決系）

フック（0〜3秒）：
「（セリフ）」

本編：
1. （カット内容とセリフ）
2. （カット内容とセリフ）
3. （カット内容とセリフ）

CTA：
「（セリフ）」

撮影メモ：（必要な素材・カット割りの補足があれば）
```

複数テーマをまとめて渡された場合は、テーマごとに上記フォーマットを繰り返し、最後に「型の重複がないか」を一覧で確認する（同じ型が3本以上連続しないよう調整する）。

## 注意点

- セリフは口語体で、実際にそのまま話せる長さ・言い回しにする（書き言葉の説明文にしない）
- 誇大表現・断定的な効果保証は避ける
- CTAは1本につき1つに絞る（詰め込みすぎると離脱率が上がる）
