# アカウント診断→提案書変換スキル

## 概要

「SNSアカウント診断→提案書シート」の `診断チェック` タブ（プロフィール／導線／投稿内容／投稿頻度・運用／デザイン／CTA・オファーの6セクション×各5項目、計30項目を○＝2点／△＝1点／×＝0点で評価）の結果を、営業・提案の場でそのまま使える文書に変換する。

シート内の `提案書` タブがすでに自動集計されている場合はその数値をベースに使う。診断結果がテキストやCSVで渡された場合も同様のロジックで処理する。

## 実行手順

### STEP1｜診断データの取得

以下のいずれかで診断結果を受け取る。

1. スプレッドシート連携：`診断チェック` タブから、アカウント名・業種・診断日・各項目の評価・セクション別小計・総合スコア・判定を取得する
2. テキスト/CSV連携：30項目の評価（○△×）が並んだデータを受け取り、同じ配点ルールで採点する

採点ルール：○=2点、△=1点、×=0点。セクション満点は10点（5項目×2点）、総合満点は60点。
判定基準：48点以上=S（強いアカウント）／36〜47点=A（良好・伸びしろあり）／24〜35点=B（伸びしろ大）／23点以下=C（基礎から改善）

### STEP2｜提案書のヘッダーを作成

```text
【〇〇様　SNSアカウント診断レポート】

診断日：〇年〇月〇日
診断対象：〇〇（アカウント名／業種）
総合スコア：〇〇 / 60点（判定：〇）
```

### STEP3｜セクション別スコアを掲載

6セクション（プロフィール／導線／投稿内容／投稿頻度・運用／デザイン／CTA・オファー）のスコアを表形式で並べる。

### STEP4｜優先改善ポイントTOP3を抽出

スコアが低い順にセクションを3つ選び、それぞれについて「なぜ低いか」「何を変えると良くなるか」を1〜2文で具体的に書く。抽象的な指摘（「もっと頑張りましょう」等）ではなく、実行可能な改善アクションに落とす。

```text
■ 優先改善ポイント
1.【〇〇】（〇/10点）｜〇〇が原因。〇〇に変えると改善が見込めます。
2.【〇〇】（〇/10点）｜〇〇
3.【〇〇】（〇/10点）｜〇〇
```

### STEP5｜良好な点も必ず1つ以上入れる

低い点だけを並べると「ダメ出し」に見えてしまうため、スコアが高い（8点以上）セクションがあれば「〇〇は良好です。この型を他のセクションにも展開しましょう」と加える。全セクションが低い場合は「まず土台から一緒に作れる状態」という前向きな言い回しにする。

### STEP6｜次のアクション（クロージング文）

診断結果から自然につながる、次の相談・提案に進むための一言で締める。

```text
■ 次のステップ
上記の優先改善ポイントから、まず①②の実装をご一緒に進めることをおすすめします。
改善案の具体化や実装代行も可能です。よろしければ個別にご相談ください。
```

### STEP7｜出力形式

デフォルトはMarkdown文書として出力し、そのまま画面共有・PDF化・メール添付できる形にする。
ユーザーが「Googleドキュメントにして」「PDFにして」と指定した場合はその形式で作成する。

## 注意点

- 診断対象の企業名・個人名・実データは、ユーザーの許可なく外部（他の顧客への提案書など）に流用しない
- 辛口すぎる指摘は避け、「診断＝営業の入口」であることを踏まえて建設的なトーンを保つ
- 数値は診断結果の範囲でのみ言及し、根拠のない推測を加えない
