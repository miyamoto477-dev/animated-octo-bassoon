# LINEステップ配信シナリオ生成スキル

## 概要

新しい商品のLINE配信シナリオを一括生成するスキル。導線設計・原則は `employees/marketing/CLAUDE.md` に準拠する。

## 引数

- 商品名：ユーザーから受け取る
- 商品の価格：ユーザーから受け取る
- ターゲット：ユーザーから受け取る

## 実行手順

### STEP1｜商品概要の取得

`employees/product/products/{商品名}_概要書.md` があれば取得する。無ければユーザーに商品概要をヒアリングする。

### STEP2｜7日間のシナリオ作成

以下の型で7日間のステップ配信シナリオを作成する。

- 1日目：お礼＋無料プレゼント
- 2日目：自己紹介ストーリー
- 3日目：即実践ノウハウ
- 4日目：よくある質問への回答
- 5日目：実績・体験談
- 6日目：商品の予告
- 7日目：商品のオファー

### STEP3｜本文作成

各日の本文を400文字以内で書く。

### STEP4｜CTA

CTAは1メッセージ1つに絞る（押し売り感を出さない）。

### STEP5｜保存

`employees/marketing/line_sequence/YYYY-MM_v1.md` に保存する。同月に既存バージョンがあれば `v2` など連番にする。

## 呼び出し例

```
LINEシナリオ作って 商品名:ChatGPT副業スターターパック 価格:5000 ターゲット:副業初心者の会社員
```
