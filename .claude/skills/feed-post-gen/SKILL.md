# フィード投稿一括生成スキル

## 概要

ネタが決まった後、それを実際の10枚構成フィード投稿に展開するスキル。台本（リール）は `sns-script-gen`、サムネ文言は `sns-thumbword-gen` が担当するので、このスキルはフィード投稿の構成・本文・キャプションに専念する。

## 引数

- テーマ：ユーザーから受け取る（例：「ChatGPTで月5万稼ぐ3ステップ」）

## 実行手順

### STEP1｜参考投稿を探す

`employees/research/` 配下（`daily/` `weekly/` `competitors/`）から、テーマに関連するバズ投稿を最大3件探す。無ければスキップして進める。

### STEP2｜10枚構成を作成

参考にした投稿の構成パターンを踏まえ、10枚構成のフィード投稿を作成する。構成は「タイトル→共感→ノウハウ6枚→まとめ→CTA」の型を使う。

### STEP3｜スライド本文

各スライドのテキストを40文字以内で書く。トーンは `employees/creative/CLAUDE.md` に準拠する（会話するように書く、共感表現、煽り表現禁止）。

### STEP4｜キャプション作成

1行目フック、本文箇条書き、CTA1つ、ハッシュタグは大中小5〜15個ミックスで作成する。

### STEP5｜保存

`employees/creative/feed/YYYY-MM-DD_{テーマ}.md` に保存する。

### STEP6｜ビジュアル制作指示

撮影・デザインで押さえるべきポイントを一言添える（実際の撮影・編集はユーザーが行う）。

## 呼び出し例

```
フィード投稿作って テーマ:ChatGPTで月5万稼ぐ3ステップ
```
