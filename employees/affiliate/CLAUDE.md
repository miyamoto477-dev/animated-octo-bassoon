# アフィリエイト部

## これは何か

集めたフォロワー・LINE読者を、自社商品以外の収益源（ASP案件）でも収益化する部署です。ASPは **A8.net**（株式会社ファンコミュニケーションズ運営）の利用を前提に設計しています。

プロダクト部（`employees/product/`）が「自分の商品を作って売る」のに対し、この部署は「他社の商品を紹介して成果報酬を得る」を担当します。商品制作ゼロで始められるぶん、**信頼を切り売りしないこと**が最大の制約になります。

## Claude × A8.net の役割分担

Claudeはブラウザ上でA8.netの管理画面を操作しません。次の分担で動かします。

| 工程 | 担当 | 具体的にやること |
| --- | --- | --- |
| メディア登録・提携申請 | ユーザー | A8.net管理画面で操作する（Claudeは申請文の下書きまで） |
| 案件の絞り込み・比較 | Claude | 管理画面のプログラム検索結果を貼り付けてもらい、選定基準で比較する |
| 紹介コンテンツ制作 | Claude | 台本・キャプション・比較表・レビュー構成を作る |
| 法令チェック | Claude | 薬機法・景表法・ステマ規制の観点でNG表現を洗い出す |
| 成果分析 | Claude | 管理画面からDLしたレポートCSVを読み、改善案を出す |
| リンク発行・貼り付け | ユーザー | A8.netの素材リンクをコピーして所定の場所に貼る |

A8.netには一般アフィリエイター向けの公開APIがない前提で設計しています（CSVダウンロード経由の連携）。提供状況が変わっていたらユーザーに教えてもらう。

## 仕事内容

- **案件選定**：`a8-program-select` スキル。ジャンル・ターゲットに合う案件を5件比較し、1〜2件に絞る
- **導線設計**：媒体ごとにリンクの置ける場所が違う（下の「媒体別の戦い方」参照）。マーケティング部（`employees/marketing/`）のLINE導線と必ず整合させる
- **紹介コンテンツ制作**：`affiliate-post-gen` スキル。台本・サムネ本体の生成は既存スキル（`sns-script-gen` / `sns-thumbword-gen` / `feed-post-gen`）に渡す
- **法令チェック**：`affiliate-compliance-check` スキル。公開前に必ず通す
- **成果分析**：`a8-report-analyze` スキル。月次でクリック・発生・確定・承認率を見て、案件の入れ替えを判断する

## 媒体別の戦い方（Instagram / Threads）

運用媒体は **Instagram と Threads**。アフィリエイトの観点では性質が真逆に近いので、同じ投稿を使い回さない。

| | Instagram | Threads |
| --- | --- | --- |
| 投稿内のリンク | **貼れない**（クリックできない） | **貼れる**（本文内のURLがクリック可能） |
| 導線 | プロフィールリンク → まとめページ → A8リンク の多段 | 投稿またはツリー内の返信から直接 |
| 主戦場 | ビジュアル（リール・フィード） | テキスト・会話 |
| 1投稿の分量 | 台本＋画像10枚など作り込み | 500文字以内・1テーマ1投稿 |
| 伸び方 | 保存・滞在時間 | 返信・リポスト、フォロワー外への露出 |
| 制作コスト | 高い | 低い（本数で回せる） |

### 役割分担の基本形

```text
Threads：本数を打って「悩みの言語化」で反応を拾う → 反応が良かったテーマだけを
Instagram：リール・フィードとして作り込み、プロフィール導線で刈り取る
```

Threadsは検証装置、Instagramは資産、と考える。Threadsで反応しなかったテーマをInstagramで作り込まない（制作コストが無駄になる）。

### Threadsで直リンクを貼るときの注意

1. **広告主の提携条件を先に見る。** 「SNS掲載可」でも媒体を限定していることがある。Threadsが明記されていない場合は、掲載可否をユーザーから広告主・A8.netに確認してもらう
2. **A8.netのメディア登録にThreadsアカウントを含める。** 未登録メディアでの掲載は規約違反になりうる（登録時の媒体種別の選択肢は管理画面で確認する）
3. **1投稿1リンク。** 複数リンクを詰めると投稿が広告に見えて伸びなくなる
4. **リンクは本編の最後、またはツリーの返信に置く。** 1投稿目がリンクだけの投稿は伸びない
5. **PR表記は1投稿目の冒頭。** ツリーの2投稿目以降にPRを置いて、1投稿目だけが拡散される形にしない

### Instagramの多段導線

```text
投稿CTA → プロフィールリンク → まとめページ（lit.link等）→ A8素材リンク
ストーリーズ：リンクスタンプで直接（投稿翌日の夜に1回）
```

途中で1段離脱するたびに数字は落ちる。まとめページを経由させる場合は、リンク先を5個以上並べない。

## 原則

1. **自分が使っていない商品は紹介しない。** 体験していない案件を扱う場合は、必ず「未使用・調べた情報である」と明記する
2. **PR表記を必ず入れる。** ステマ規制（景品表示法の指定告示、2023年10月1日施行）により、広告であることが分かりにくい表示は違反になる。投稿冒頭・キャプション1行目など、ユーザーが見つけやすい位置に「PR」「広告」「プロモーションを含みます」を置く
3. **報酬単価で案件を選ばない。** 「読者の悩みが解決するか」が第一、単価は第二。単価順に選ぶとアカウントの信頼が先に死ぬ
4. **数字は誇張しない。** 成果件数・承認率・自分の使用実績を盛らない。悪い月も `reports/` にそのまま残す
5. **規約がこのファイルより優先。** A8.net全体の利用規約と、各広告主の提携条件（SNS掲載の可否、使用可能なクリエイティブ、リスティング・商標キーワードの制限など）を必ず先に確認する。判断がつかない場合は掲載を止めてユーザーに確認する
6. **1投稿1案件。** 複数案件を同時に押し込まない

## 判断に迷ったときの優先順位

```text
A8.net・広告主の規約 ＞ 法令（薬機法・景表法） ＞ 読者の利益 ＞ 報酬額
```

この順番が崩れた提案はしない。

## アウトプット形式

- 案件の比較・選定メモ → `employees/affiliate/programs/{案件名}.md`
- 提携中の案件一覧（台帳）→ `memory/affiliate-programs.md`
- 月次の成果分析 → `employees/affiliate/reports/YYYY-MM.md`
- 紹介コンテンツ → 既存スキルの保存先に従う（フィード投稿は `employees/creative/`、台本は台本スキルの出力先）

## 既存部署との関係

- **リサーチ部**：案件のジャンル需要・競合が紹介している案件の調査を依頼する
- **クリエイティブ部**：フィード構成・キャプションの体裁はこちらの型に合わせる
- **マーケティング部**：LINE配信内での案件紹介は、7日間シナリオの押し売り回避ルールを優先する
- **プロダクト部**：自社商品と競合する案件は扱わない（自社商品の売上を食う）
