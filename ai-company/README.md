# AIマーケ会社｜10人の組織

## これは何か

制作・リサーチ・執筆・動画・SNS・商品化までを、**10人のAI社員で分担して回す**ための組織です。
フォルダ1つ＝社員1人。そのフォルダでClaude Codeを開くと、その社員として振る舞います。

## 組織図

```text
                        leader（統括・戦略・朝晩の報告）
                              │
        ┌──────────────┼──────────────┐
        ▼                     ▼                     ▼
   【考える】            【作る】              【見る】
   brunson               writer                analyst
   （壁打ち顧問）         （セールス文章）        （ファネル分析）
   researcher            designer                  │
   （Web＋Xの調査）       （画像生成）              │
        │                 lp                       │
        │                （LP制作）                 │
        │                 video                    │
        │                （字幕・編集）             │
        │                 sns                      │
        │                （投稿画像の量産）          │
        │                 product                  │
        │                （教材・特典ページ）        │
        └─────────────────┴──────────────────┘
                     出したあとの数字が analyst に戻る
```

## 10人の一覧

| フォルダ | 役割 | 得意なこと | 使うときの合図 |
| --- | --- | --- | --- |
| `members/leader` | 統括・戦略・報告 | 工程の整理、優先順位、朝晩の報告 | 「今日どうする」「全体を整理して」 |
| `members/brunson` | マーケ壁打ち顧問 | オファーの設計、本音の意見 | 「売り方に迷っている」「これどう思う」 |
| `members/researcher` | リサーチ | Web検索＋Xの一次情報を両輪で | 「競合を調べて」「裏を取って」 |
| `members/writer` | セールスライティング | セールス8ステップでの執筆 | 「文章を書いて」「見出しを出して」 |
| `members/designer` | 画像生成 | LP画像・サムネ・バナーを複数モデルで並列生成 | 「画像を作って」「サムネを」 |
| `members/lp` | LP制作 | HTML+TailwindでLPを組む | 「LPを作って」「申込ページを」 |
| `members/video` | 動画編集・字幕 | 字幕焼き込み、縦横の変換 | 「字幕を付けて」「縦動画にして」 |
| `members/sns` | SNS画像量産 | Figmaテンプレで投稿画像を量産 | 「投稿画像を30枚」 |
| `members/product` | 商品・教材制作 | 特典ページ・教材を型化して量産 | 「教材にして」「マニュアルを」 |
| `members/analyst` | データ分析 | ファネルのボトルネック特定と改善TOP3 | 「数字が伸びない」「どこを直す」 |

## 各社員のフォルダ

```text
members/<役割>/
├── CLAUDE.md    役割定義（Claudeがこれを読んで振る舞います）
├── inbox/       あなたが置く入力（素材・依頼メモ・参考URL・元データ）
└── projects/    その社員が作った成果物
```

**入力は `inbox/` に置き、成果物は `projects/` に残す。** これだけ守れば、社員どうしで引き継げます。

## 使い方

### パターンA：全体を相談したい

`ai-company/` または `members/leader/` でClaude Codeを開きます。
統括が工程を整理し、どの社員に何を頼めばよいか案内します。

### パターンB：担当を決めて頼みたい

その社員のフォルダを開きます。

```bash
cd ai-company/members/writer
claude
```

そのあと「あなたの役割を教えて」と聞いて、セールスライターとして名乗れば成功です。

### パターンC：流れで頼みたい

たいていの仕事は1人では終わりません。よくある連なりはこれです。

| やりたいこと | 社員の順番 |
| --- | --- |
| LPを作って売る | researcher → brunson → writer → designer → lp → analyst |
| SNSを回す | researcher → writer → sns → analyst |
| 教材・特典を作る | brunson → product → designer → lp |
| 動画を出す | writer → video → designer（サムネ）→ analyst |

迷ったら `members/leader` に「〇〇をやりたい」と言えば、この順番を組み立てます。

## 全体ルール

10人共通のルールは `CLAUDE.md` にあります。各社員の `CLAUDE.md` は、このルールに従う前提で書かれています。

特に全員が守るもの：

- **日本語・敬語で応対する**（`brunson` だけ例外。壁打ちなのでカジュアル）
- **数字を誇張しない。悪い数字も隠さない**
- **「必ず」「絶対に」「確実に」を効果に付けない**
- **作ったものは `projects/` に残す**
- **元に戻せないこと（支払い・公開・削除）は、必ず先に確認する**
