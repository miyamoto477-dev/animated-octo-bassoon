# templates（Figmaテンプレート集）

このフォルダには、②テンプレ選定の工程で使う、Figmaテンプレートの候補一覧を常設で管理してください。
案件ごとの `projects/` とは異なり、ここは複数の案件で使い回す「テンプレートのライブラリ」です。

## 管理する内容

- テンプレートごとの候補メモ（1テンプレート＝1ファイル、または一覧ファイルにまとめる）
- FigmaのURL（リンク）
- テンプレートの特徴（型：ノウハウ系／実績紹介／ビフォーアフター等、雰囲気、向いているジャンル）
- 各テキスト枠の文字数目安（④文字数チェックで使う基準値）

## 記載フォーマットの例

```text
## テンプレート名：〇〇型（ノウハウ系）

- Figma URL：（リンク）
- 特徴：〇〇
- 向いているジャンル：〇〇
- テキスト枠の文字数目安：
  - タイトル：〇〇文字以内
  - 本文：〇〇文字以内
```

## 運用ルール

- 新しいテンプレートを追加・入手したら、案件対応の前にこのフォルダへ登録する
- テンプレートを更新・差し替えた場合は、このフォルダのメモも合わせて更新する
- 案件固有の使い方・カスタマイズ内容は、ここではなく `../projects/案件名/` 側に記録する
