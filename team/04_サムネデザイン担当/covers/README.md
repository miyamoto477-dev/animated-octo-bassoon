# Instagram表紙画像ジェネレーター

投稿の表紙（リールのカバー／フィード1枚目）を、**JSONを書き換えるだけで量産**する仕組み。
毎回デザインを一から作らないための、このアカウント専用のテンプレート。

## なぜこれがあるか

サムネは「毎回違うデザイン」にすると、フィードに並べたときバラバラに見えてアカウントが安っぽくなる。
逆に**同じ型で文言だけ変える**と、並べた瞬間に「ちゃんと運用されているアカウント」に見える。
そのため、レイアウトは固定して、変えるのは文言だけにしてある。

## 使い方

```bash
cd team/04_サムネデザイン担当/covers
npm i playwright          # 初回のみ
node render-covers.mjs
```

`out/` に `no06.png` のように1080×1350（Instagram推奨の4:5）で書き出される。

## 文言の変え方

`covers.config.json` の `posts` に追記するだけ。

```json
{
  "id": "no10",
  "theme": "男性が本命に見せるサインの見分け方",
  "kicker": "保 存 版",
  "setup": ["彼が本命の女性にだけ", "見せる行動があります。"],
  "layout": "text",
  "headline": ["見分け方は、", "この[[3つ]]です"],
  "sub": "当てはまってますか？"
}
```

| キー | 役割 |
| --- | --- |
| `id` | 出力ファイル名。運用管理シートのNoに合わせる |
| `kicker` | 左上のピンクのタグ。「保 存 版」「よくいただく相談」など |
| `setup` | 導入の2行。悩みを提示して自分ごと化させる |
| `headline` | 一番大きい文字。**1行7文字以内**（はみ出すと警告が出る） |
| `sub` | 締めの一言。赤字で補足 |
| `layout` | `text`（通常）か `number`（数字を主役にする型） |
| `badge` | 任意。`"Q."` を入れると右上に薄く大きな装飾が入る |

`[[…]]` で囲んだ部分に蛍光ペンのマーカーが入る。**1行につき1箇所だけ**にすること。

## 守るルール

- 見出しは**7文字以内 × 2行**まで。それ以上は読ませる前にスクロールされる
- マーカーは1枚に1箇所。全部強調は、何も強調していないのと同じ
- `layout: "number"` は数字が主役のテーマ（「3つだけ」「5選」など）にだけ使う
- 色（`brand`）は変えない。統一されていることがこのテンプレートの価値

## 投稿までの流れ

1. ここで表紙を書き出す
2. 画像をCloudinaryなどにアップして固定URLにする（Make自動投稿を使う場合）
3. `content/` のキャプションと組み合わせて投稿

> Canvaの書き出しURL（`export-download.canva.com/...`）は**署名付きの一時URLで、すぐ無効になる**。
> 自動投稿に渡すと `Only photo or video can be accepted as media type` で失敗するので、
> 必ずCloudinaryなど恒久URLに置き換えること。
