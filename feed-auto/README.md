# feed-auto フォルダについて

Instagramフィードへの自動投稿を待っている「画像＋キャプション」を置く場所です。
毎日cronで実行される `scripts/instagram-auto-post/post-to-instagram.js` が、このフォルダを見て1件だけ投稿します。

## 置き方

画像ファイルとキャプションファイルを、**同じファイル名（拡張子だけ違う）** でこのフォルダ直下に置いてください。

```
feed-auto/
  01_新作紹介.jpg
  01_新作紹介.txt   ← 中身がそのままキャプションになる
  02_お客様の声.png
  02_お客様の声.txt
```

- 画像：`.jpg` `.jpeg` `.png` に対応
- キャプション：同名の `.txt`（中身をそのままテキストで書くだけ）
- ファイル名は**ファイル名順（アルファベット・数字順）に古い方から1件ずつ**投稿されるので、`01_`, `02_`... や `2026-08-16_` のように番号・日付を先頭につけて、投稿したい順番になるよう命名してください
- 画像だけあってキャプション（同名の.txt）がない場合、その画像はスキップされます（投稿されません）。キャプションを追加すれば次回から投稿対象になります

## 投稿後の動き

投稿に成功すると、画像とキャプションの両方が自動で `feed-auto/posted/` に移動します。
一度投稿されたものは feed-auto 直下からなくなるので、同じ投稿が二重に投稿されることはありません。

投稿に失敗した場合（API エラーなど）はファイルをこのフォルダに残したままにするので、次回のcron実行時に自動で再試行されます。詳細は `logs/instagram-auto-post.log` を確認してください。

セットアップ方法（Instagram連携・cron設定など）は `scripts/instagram-auto-post/README.md` を参照してください。
