# feed-auto｜投稿ネタ＋キャプション＋画像セット

作成日：2026-08-16
テーマ：彼氏との人間関係の悩み（30代女性向け）

自動投稿用にまとめた投稿素材一式です。

| ファイル | 内容 |
| --- | --- |
| `post-ideas.md` | 投稿企画30本（切り口・ターゲット心理・フォーマット・フック案） |
| `captions.md` | 30本分のキャプション（フック＋本文箇条書き＋CTA＋ハッシュタグ） |
| `images.md` | 表紙画像（9:16, AI生成）のURL一覧。生成済み10本＋汎用カバー1本、未生成分の一覧つき |

## 使い方の想定

1. `post-ideas.md` で投稿する企画Noを選ぶ（まずはおすすめ5本：No.1, 2, 7, 8, 10）
2. `captions.md` から同じNoのキャプションをコピー
3. `images.md` から同じNoの画像URLを取得し、必要であれば表紙文字（フック案）をCanva等で乗せる
4. 自動投稿ツール（Make等）にキャプション＋画像URLを渡す

## 未対応・要確認事項

- 商品・サービスが未確定のため、No.17〜19（商品・サービス紹介枠）は「共感発信＋緩いLINE誘導」の想定で作成しています。実際の商品・サービスが決まったら教えてください。内容を差し替えます。
- 画像は10本＋汎用1本のみ生成済み（APIクォータの都合）。残り19本の画像が必要な場合はお知らせください。
- Cloudinary CDNから画像ファイルをこのリポジトリに直接ダウンロードすることは、実行環境のネットワークポリシー上できません。画像はCloudinary側に保存されているURLを直接ご利用ください。
