# feed-auto セットアップ手順（Windows）

Instagram公式のGraph API（Meta公式）を使って、`feed-auto/pending` の投稿を毎日自動で公開できるようにするまでの手順です。全体で30〜60分ほどかかります。一度設定すれば、以降は `pending/` に画像とキャプションを入れるだけで運用できます。

全体の流れ：

1. Instagramをビジネス/クリエイターアカウントに切り替える
2. Facebookページと連携する
3. Meta for Developersでアプリを作成し、アクセストークンを発行する
4. imgbb（画像の一時公開URL化）のAPIキーを取得する
5. パソコン（Windows）にPythonをセットアップする
6. `.env` に認証情報を入力する
7. 手動テストする
8. タスクスケジューラに毎日9時の自動実行を登録する

---

## STEP1｜Instagramをビジネス/クリエイターアカウントにする

Instagram Graph APIで投稿できるのは「ビジネスアカウント」または「クリエイターアカウント」のみです（個人アカウントのままでは投稿APIは使えません）。

1. Instagramアプリ → プロフィール → 右上のメニュー → 「設定とプライバシー」→「アカウントの種類とツール」
2. 「プロアカウントに切り替える」→ ビジネス（またはクリエイター）を選択
3. 案内に沿ってカテゴリなどを設定（無料・審査なしで即切り替わります）

## STEP2｜Facebookページと連携する

Instagram Graph APIは、Instagramアカウントに紐づくFacebookページ経由でアクセスします。

1. Facebookページを持っていない場合は [facebook.com/pages/create](https://www.facebook.com/pages/create) で作成（名前は何でもOK。連携専用でも構いません）
2. Instagramアプリ内の「プロアカウントに切り替える」の続きで、作成したFacebookページと連携する（または プロフィール→設定→「アカウントセンター」→「連携済みの経験」からFacebookページを接続）

## STEP3｜Meta for Developersでアプリを作成し、アクセストークンを発行する

1. [developers.facebook.com](https://developers.facebook.com/) に、Instagram/Facebookと同じアカウントでログイン
2. 「マイアプリ」→「アプリを作成」→ 用途は「その他」→ タイプは「ビジネス」を選択して作成
3. アプリのダッシュボードで「製品を追加」から **Instagram Graph API** を追加
4. 画面右上メニューまたは [グラフAPIエクスプローラー](https://developers.facebook.com/tools/explorer/) を開く
5. 「User or Page」→ 自分のアプリを選択 →「Get Token」→「Get User Access Token」
6. 権限（Permissions）で以下にチェック：
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`
   - `pages_read_engagement`
7. 「Generate Access Token」→ 発行された短期トークンをコピー
8. このトークンは有効期限が短い（1〜2時間）ため、長期トークンに交換する。ブラウザまたはグラフAPIエクスプローラーで以下を実行：

   ```
   GET /oauth/access_token
     ?grant_type=fb_exchange_token
     &client_id={アプリID}
     &client_secret={アプリシークレット}
     &fb_exchange_token={STEP7で取得した短期トークン}
   ```

   アプリID・アプリシークレットは アプリダッシュボード→「設定」→「ベーシック」で確認できます。返ってきた `access_token` が約60日間有効な長期トークンです。

9. Instagramビジネスアカウント ID（`IG_USER_ID`）を調べる：

   ```
   GET /me/accounts?access_token={長期トークン}
   ```
   で自分のFacebookページID（`id`）を確認し、続けて

   ```
   GET /{ページID}?fields=instagram_business_account&access_token={長期トークン}
   ```
   を実行すると `instagram_business_account.id` が返ってくる。これが `IG_USER_ID`。

> ⚠️ 長期トークンは約60日で失効します。切れる前に本スクリプトが警告を表示するので、その際はSTEP3を再度実施してトークンを再発行してください（本格運用する場合は、失効させたくない旨をMetaアプリ審査で相談する方法もありますが、個人利用の範囲ではこの60日ごとの更新が最も簡単です）。

## STEP4｜imgbbのAPIキーを取得する

Instagram Graph APIに画像を渡すには「公開URL」が必要です（パソコン内のファイルを直接アップロードする方式ではありません）。ここでは無料の画像ホスティングサービス [imgbb](https://imgbb.com/) を使い、投稿のたびに自動で一時公開URLを発行します。

1. [api.imgbb.com](https://api.imgbb.com/) にアクセスし、無料アカウントを作成
2. 表示されるAPIキーをコピー

## STEP5｜パソコン（Windows）にPythonをセットアップする

1. [python.org](https://www.python.org/downloads/) から最新版をダウンロードしてインストール
   - インストーラー画面で **「Add python.exe to PATH」に必ずチェック**を入れる
2. コマンドプロンプト（またはPowerShell）を開き、このリポジトリのフォルダに移動して以下を実行：

   ```powershell
   cd path\to\animated-octo-bassoon
   pip install -r feed-auto\scripts\requirements.txt
   ```

## STEP6｜`.env` に認証情報を入力する

1. `feed-auto\.env.example` を同じフォルダに `.env` という名前でコピー
2. `.env` をメモ帳などで開き、STEP3・STEP4で取得した値を入力：

   ```
   IG_USER_ID=（STEP3-9で取得した数字）
   ACCESS_TOKEN=（STEP3-8で取得した長期トークン）
   IMGBB_API_KEY=（STEP4で取得したAPIキー）
   ```

## STEP7｜手動テストする

まずは投稿対象を1件だけ `pending/` に入れて試します。

```powershell
cd path\to\animated-octo-bassoon
python feed-auto\scripts\post_to_instagram.py
```

- 「投稿完了」と表示され、Instagramアプリで実際に投稿が公開されていれば成功
- 対象のファイルが `pending/` から `posted/` に移動していることを確認
- エラーが出た場合は `feed-auto\failed\` に移動したファイルと同名の `.error.txt` を確認（多くは権限不足・トークン期限切れ・アカウント種別の設定漏れが原因）

## STEP8｜タスクスケジューラに毎日9時の自動実行を登録する

1. Windowsの検索バーで「タスクスケジューラ」を開く
2. 右側の「基本タスクの作成」をクリック
3. 名前：`Instagramフィード自動投稿`（任意）→ 次へ
4. トリガー：「毎日」→ 次へ → 開始時刻に `9:00:00` を設定 → 次へ
5. 操作：「プログラムの開始」→ 次へ
6. プログラム/スクリプト欄に、`feed-auto\scripts\run_post.bat` の**フルパス**を指定（例：`C:\Users\ユーザー名\Desktop\animated-octo-bassoon\feed-auto\scripts\run_post.bat`）
7. 「完了」をクリック
8. 作成したタスクを右クリック→「プロパティ」を開き、以下を確認・変更：
   - 全般タブ：「ユーザーがログオンしているかどうかにかかわらず実行する」にチェックすると、ログオフ中でも実行されます（その場合Windowsのパスワード入力が必要になることがあります）
   - 条件タブ：「AC電源で実行する場合のみ」のチェックを外す（ノートPCの場合。バッテリー駆動時も動かすため）
   - 設定タブ：「スケジュールされた時刻に実行できなかったらできるだけ早くタスクを実行する」にチェック（PCがスリープ中で9時を過ぎても、起動後に投稿されるようにする）

> ⚠️ パソコンの電源が入っていない・スリープ中のままだと、その日は投稿されません（次回起動時に持ち越されます。上記「できるだけ早く実行」設定でカバーできます）。パソコンを毎朝つけっぱなしにするか、9時前後は起動しておく運用にしてください。

### 動作確認

タスクスケジューラの一覧で対象タスクを右クリック→「実行」を選ぶと、スケジュールを待たずに今すぐテストできます。実行結果は `feed-auto\logs\task_scheduler.log` と `feed-auto\logs\post_log.csv` で確認できます。

## トラブルシューティング

| 症状 | 主な原因 |
| --- | --- |
| `.env に ... が設定されていません` | `.env` の作成漏れ、または値の入力漏れ |
| `メディアコンテナ作成失敗` | アクセストークンの権限不足／期限切れ、`IG_USER_ID` の間違い |
| `imgbbアップロード失敗` | `IMGBB_API_KEY` の間違い、画像サイズ超過（32MB以下推奨） |
| 投稿されるがキャプションが空 | `.txt` ファイルの文字コードを確認（UTF-8で保存） |
| タスクスケジューラで実行されない | パス指定の誤り、PCがスリープ中だった、Pythonが `PATH` に通っていない |

困ったときは `feed-auto\logs\post_log.csv` と、失敗ペアと同名の `feed-auto\failed\〇〇.error.txt` を確認してください。
