# 提携中アフィリエイト案件 台帳（A8.net）

提携した案件をここに記録しておくと、投稿作成・成果分析のたびに条件を調べ直さずに済みます。
`a8-program-select` で提携が決まったとき、`a8-report-analyze` で数字が出たときに、Claudeが追記・更新します。

## A8.net メディア登録状況

| 媒体 | 登録 | 備考 |
| --- | --- | --- |
| Instagram | 登録済み | 投稿内リンク不可。プロフィール導線で刈り取る |
| Threads | 登録済み（2026-09） | 本文に直リンク可。ただし案件ごとにThreads掲載可否を確認する |

媒体を分けて登録済みのため、素材リンクを媒体別に発行すれば `a8-report-analyze` で媒体別EPCを比較できる。**投稿を作るときは媒体に対応したリンクを使う。**

## ジャンル前提（案件選定の判断材料）

- ジャンル：美容・健康 ／ ターゲット：30代女性
- **このジャンルは薬機法の制約が最も厳しい。** 案件選定時に「報酬」だけでなく **表現の自由度**（広告主がどこまでの訴求を許可しているか、NG表現リストの有無）を必ず確認する
- 定期縛りのある案件はキャンセルが出やすく承認率が下がりやすい。単品・トライアル型と分けて記録する

## 各案件の掲載条件メモ

広告主ごとの禁止事項（SNS掲載不可、商標キーワード出稿禁止、クリエイティブ改変不可など）を書いておく。**この台帳より広告主の最新の提携条件が優先。**

- （例）〇〇：Instagram掲載可・動画への素材使用は不可
