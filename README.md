# AI社員「SNS運用代行」スターターOS セットアップガイド

## 必要なもの

- Claude Code（[claude.com/code](https://claude.com/code) からインストール）
- このフォルダ一式

導入がまだの方は、登録特典「Claude Code セットアップガイド」を先にご覧ください。

## セットアップ手順（5分）

### STEP1｜フォルダを配置する

このフォルダを、パソコンの好きな場所に置いてください。
例：デスクトップ、ドキュメント内など。

### STEP2｜Claude Codeでこのフォルダを開く

ターミナル（Mac）またはコマンドプロンプト（Windows）で、このフォルダに移動してから起動します。

```bash
cd path/to/このフォルダ
claude
```

※パスの入力が面倒な場合は、`cd ` と入力したあとにフォルダをターミナルへドラッグ＆ドロップすると自動でパスが入ります。

### STEP3｜起動を確認する

Claude Codeが起動したら、試しに次のように話しかけてみてください。

```text
あなたの役割を教えて
```

`CLAUDE.md` の内容（AI社員としての役割）を理解して返答すれば、セットアップ完了です。

### STEP4｜SNS運用管理シートと連携する（お持ちの方）

Day3参加特典で配布した「エヌイチ式 SNS運用管理シート」をお持ちの場合は、そのスプレッドシートのURLをClaude Codeに伝えてください。

```text
このSNS運用管理シートを使います：（スプレッドシートのURL）
```

以降、企画の書き込みや数値の読み込みをこのシートと連携して行います。

## 使い方の例

```text
「新規で美容室のインスタ運用を始めます。ターゲットは30代女性、悩みは白髪と縮毛です。投稿企画30本作って」

「①の企画で台本作って」

「この投稿のサムネワード出して」

「今月の数字まとめて月次報告作って（数字を貼り付け）」

「このアカウント診断結果を提案書にして」
```

## 含まれるスキル一覧

| スキル | できること |
| --- | --- |
| `sns-kikaku-30` | 投稿企画30本を自動生成 |
| `sns-script-gen` | 台本（フック・構成・CTA）を自動生成 |
| `sns-thumbword-gen` | サムネイル・表紙テキスト案を自動生成 |
| `client-report-gen` | 月次クライアント報告書を自動生成 |
| `account-diagnosis-proposal` | アカウント診断結果を提案書に変換 |

## 部署体制について（拡張）

`employees/` フォルダには、企画パイプラインだけではカバーしない相談（競合分析、コメント・DM対応、LINE導線設計、商品企画）のための役割定義が5部署分入っています。

| 部署 | できること |
| --- | --- |
| `employees/research/` | 競合アカウント分析・バズ投稿調査・トレンド調査 |
| `employees/creative/` | フィード構成・ストーリーズ文言・キャプション作成 |
| `employees/community/` | コメント・DM・コメント返信文の作成 |
| `employees/marketing/` | インスタ→LINE導線設計・LINE配信シナリオ |
| `employees/product/` | 商品企画・制作 |

使い方は既存スキルと同じで、該当する相談をそのままClaude Codeに話しかければOKです（例：「競合の◯◯さんのアカウントを分析して」「今日送るコメント文を20件作って」）。Claudeが自動で該当部署の方針を参照して動きます。

## 拡張スキル一覧（部署連携）

日々の運用でよく使う作業を、追加のスキルとしてまとめています。

| スキル | できること |
| --- | --- |
| `weekly-content-ideas` | リサーチ部のログをもとに来週分の投稿ネタを5本出す |
| `feed-post-gen` | テーマを渡すと10枚構成のフィード投稿とキャプションを生成 |
| `daily-summary` | 今日のtodos・各部署の動きをまとめて明日への引き継ぎを作る |
| `competitor-analysis` | 指定した1アカウントを深掘り分析する |
| `line-sequence-gen` | 商品名・価格・ターゲットから7日間のLINEステップ配信シナリオを生成 |
| `comment-batch-gen` | 今日送るコメント文を指定件数まとめて生成 |
| `weekly-report` | 先週1週間の運用結果を社内向けに振り返る（クライアント向け月次報告は `client-report-gen`） |

## 投稿・配信まわり（setup / content / projects）

企画や台本ができたあと、実際に「出す」工程のためのフォルダです。

| 場所 | 中身 |
| --- | --- |
| `setup/01-line-delivery.md` | LINE配信の書き方・送信前チェックリスト |
| `setup/02-x-posting.md` | X投稿のやり方（手動 / API）と反応の記録方法 |
| `content/ideas.md` | ネタのストック。思いついたら1行だけ足しておく |
| `content/x投稿.csv` | X投稿の管理表（下書き / 予約済 / 投稿済） |
| `content/配信ログ.csv` | LINE配信の記録（送信数・開封・クリック） |
| `projects/` | 案件ごとの作業フォルダ（`projects/README.md` に構成を記載） |

**LINEもXも、自動送信はしません。** Claudeは下書きを作るところまでを担当し、送信ボタンは必ずご自身で押してください。一斉配信は取り消せません。

話しかけ方の例：

```text
「明日のX投稿の下書きを5本作って、content/x投稿.csv に足して」

「LINE一斉配信の下書き作って。新特典のお知らせ、リンクは（URL）」

「content/ideas.md のネタから、今週書けそうなものを3つ選んで」
```

## 困ったときは

- **フォルダを開いても中身が少なく見える場合**：スキルは `.claude/skills/` という隠しフォルダに入っています。Finderで `command + shift + .` を押すと表示されます（もう一度押すと非表示に戻ります）。中身が見えなくてもClaude Codeからは正常に使えます。
- Claude Codeの基本操作が分からない場合は、登録特典「Claude Code セットアップガイド」をご確認ください。
- スキルが反応しない場合は、`.claude/skills/` の中に各スキルのフォルダ（その中に `SKILL.md`）が入っているか確認してください。
